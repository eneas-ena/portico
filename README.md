# Pórtico

A porta de entrada para todos os apps: os mais usados em destaque e os demais num carrossel, com cadastro próprio.

**Abrir o app:** https://eneas-ena.github.io/portico/

## Como funciona

- App feito em página web; abre direto no navegador.
- Os dados ficam salvos no Supabase, por isso aparecem iguais em todos os aparelhos.

## Observações

- A lista de apps fica num projeto Supabase próprio, separado dos demais.
- O arquivo em `.github/workflows/` é uma tarefa automática que mantém o banco de dados ativo; não apague.

## Como publicar uma nova versão

1. Nesta página do repositório, clique em **Add file → Upload files**.
2. Arraste os arquivos novos, com os mesmos nomes dos antigos.
3. Clique em **Commit changes**.

Em um ou dois minutos a nova versão está no ar no mesmo endereço.
