Sincronizar entre aparelhos desligada
Tabela exigida no Supabase (rode uma vez)

Abra o SQL Editor do seu projeto e rode este comando. Sem essa tabela, a sincronização acusa falha:

create table if not exists portico_estado (
  id text primary key,
  dados jsonb not null,
  carimbo bigint not null default 0
);

alter table portico_estado enable row level security;

create policy "portico_acesso" on portico_estado
  for all to anon using (true) with check (true);

Essa política deixa quem tiver a chave anon ler e gravar a tabela. Como aqui só ficam nomes e endereços dos seus apps, é um risco pequeno — mas não guarde nada sigiloso nela.

Sem o Supabase ligado, cada endereço (esta prévia, o GitHub Pages, o celular) guarda a lista separadamente — nesse caso use exportar e importar. Com o Supabase ligado, os três passam a ver a mesma lista.
